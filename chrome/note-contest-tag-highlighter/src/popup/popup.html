note Contest Tag Highlighter

利用前の確認

この拡張機能は、note.comの記事公開設定画面のURLと画面上のテキストを読み取り、ハッシュタグを見つけてお題タグと照合します。

読み取りと照合はこのブラウザ内で行います。記事のURLや画面上のテキストを開発者や第三者へ送信・保存しません。公開タグ一覧は note.com から取得し、この端末に保存します。

同意しない場合、記事画面の読み取りとハイライトは行いません。
