# プライバシーポリシー — note Contest Tag Highlighter

最終更新日：2026年10月29日

## 目的

note Contest Tag Highlighter は、note.com の記事公開設定画面で、コンテストやお題に関連するハッシュタグを見つけやすくする拡張機能です。note.com とは独立した製品であり、note.com から承認や推奨を受けているものではありません。

## 取り扱う情報

利用者が拡張機能のポップアップで同意した後、記事公開設定画面のURLと画面上のテキストを読み取り、ハッシュタグを特定して公開タグ一覧と照合します。URLと画面上のテキストはブラウザー内で処理し、拡張機能には保存せず、開発者や第三者にも送信しません。

拡張機能は `https://note.com/contests` から公開されているコンテスト・お題のタグ一覧を取得し、その一覧、更新日時、同意状態を Chrome の拡張機能用ローカルストレージに保存します。タグ一覧の取得リクエストに note.com のCookieや認証情報は含めません。アカウントの認証情報、記事本文、広告識別子、アクセス解析情報は収集しません。

## 利用と共有

記事ページのURLやハッシュタグのテキストを販売・共有したり、広告、プロファイリング、アクセス解析に利用したりしません。取り扱う情報は、拡張機能の目的に必要な範囲に限って利用し、Chrome Web Store ユーザーデータポリシーの Limited Use 要件を含む適用ポリシーに従います。

公開タグ一覧を取得する際、リクエストは note.com に直接送信されます。通常の通信と同様、note.com はリクエスト元のIPアドレスなどの接続情報を受け取る場合があります。リクエストに現在の記事URLやハッシュタグのテキストは含まれません。

## 保存期間と利用者による管理

公開タグ一覧は Chrome の拡張機能用ローカルストレージに保存され、およそ1日ごとに更新されます。同意状態も同じストレージに保存されます。表示中のページURLとハッシュタグのテキストは、機能の実行中にメモリー上でのみ扱います。

利用者はポップアップから同意を取り消せます。取り消すとページの監視を停止し、拡張機能が付けたハイライトを削除します。拡張機能を削除すると、Chrome が拡張機能用に保存したデータも削除します。
