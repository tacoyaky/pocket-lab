# Chrome Web Store assets

- `small-promo-tile.png`: 440×280 promotional tile for the Chrome Web Store.
- `screenshots/`: capture real extension screens here before submission.

The store requires at least one actual product screenshot at 1280×800 or 640×400. Capture the note.com publishing screen with a matching tag highlighted and the extension popup. Remove account details, article titles, note IDs, and other private content before uploading. The screenshots shared during development are not available in the repository, so no fabricated screenshot is included.

The extension's existing icon PNGs are stored in `../icons/` and are packaged without modification.
